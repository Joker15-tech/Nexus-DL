# 5. INSTALLATION WEB (Interface Web)
# ============================================================================

## Architecture

L'interface web comprend deux composants :
1. **Backend** : API REST FastAPI (Python)
2. **Frontend** : Interface Next.js (Node.js)

## 5.1 Installation Backend

### Prérequis
- Python 3.11+
- Dépendances de base installées

### Installation

```bash
# Installer FastAPI et Uvicorn
pip install fastapi uvicorn[standard]

# Ou installer toutes les dépendances web
pip install -r requirements-web.txt

# Dépendances supplémentaires recommandées
pip install python-multipart pyjwt bcrypt
```

### Vérification

```bash
# Vérifier que FastAPI est installé
python -c "import fastapi; print(fastapi.__version__)"

# Vérifier qu'Uvicorn est installé
python -c "import uvicorn; print(uvicorn.__version__)"
```

### Lancement Backend

```bash
# Lancer le backend seul
nexusdl --web

# Ou avec options
nexusdl --web --host 0.0.0.0 --port 8000

# Mode développement (avec rechargement automatique)
nexusdl --web --reload

# Mode production (plusieurs workers)
nexusdl --web --workers 4

# Ou directement avec Python
python -m nexusdl.interfaces.web.backend.main
```

### Accès Backend

- API : http://localhost:8000/api/v1
- Documentation Swagger : http://localhost:8000/docs
- Documentation ReDoc : http://localhost:8000/redoc
- Health check : http://localhost:8000/health

## 5.2 Installation Frontend

### Prérequis
- Node.js 18.17+
- pnpm (recommandé) ou npm

### Installation

```bash
# Naviguer vers le dossier frontend
cd src/nexusdl/interfaces/web/frontend

# Installer pnpm (si pas déjà fait)
npm install -g pnpm

# Installer les dépendances
pnpm install

# Ou avec npm
npm install
```

### Configuration

```bash
# Copier le fichier d'environnement
cp .env.example .env.local

# Éditer .env.local
nano .env.local
```

Contenu de .env.local :

```bash
# URL de l'API backend
NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1

# URL du WebSocket backend
NEXT_PUBLIC_WS_URL=ws://localhost:8000/ws

# Nom de l'application
NEXT_PUBLIC_APP_NAME=NexusDL

# Version de l'application
NEXT_PUBLIC_APP_VERSION=0.1.0
```

### Lancement Frontend (Mode Développement)

```bash
# Depuis le dossier frontend
pnpm dev

# Ou avec npm
npm run dev
```

Le frontend sera accessible sur : http://localhost:3000

### Build Frontend (Mode Production)

```bash
# Construire le frontend
pnpm build

# Ou avec npm
npm run build

# Démarrer le serveur de production
pnpm start

# Ou avec npm
npm start
```

### Analyse du Bundle

```bash
# Analyser la taille du bundle
pnpm analyze

# Ou avec npm
npm run analyze
```

## 5.3 Lancement Combiné (Backend + Frontend)

```bash
# Lancer les deux en même temps
nexusdl --web --dev

# Ou avec le script Python
python -m nexusdl.interfaces.web
```

Cela lancera :
- Backend sur http://localhost:8000
- Frontend sur http://localhost:3000

## Fichier de Configuration

Le fichier de configuration principal est :

```bash
# Linux/macOS
~/.config/nexusdl/config.yaml

# Windows
%APPDATA%\nexusdl\config.yaml
```

## Création du Fichier de Configuration

```bash
# Générer un fichier de configuration par défaut
nexusdl --reset-config

# Ou copier l'exemple
cp config/config.example.yaml ~/.config/nexusdl/config.yaml
```

## Configuration Minimale

```yaml
# ~/.config/nexusdl/config.yaml

app:
  language: fr
  theme: cyberpunk
  timezone: Europe/Paris

download:
  max_concurrent_tasks: 5
  max_concurrent_pages: 10
  default_format: cbz
  default_quality: original
  output_dir: ~/manga

library:
  path: ~/manga-library
  auto_scan: true
  scan_interval_minutes: 60

network:
  timeout: 30
  max_connections: 100
  verify_ssl: true

logging:
  level: INFO
  format: text
  file_enabled: true
```

## Variables d'Environnement

```bash
# Configuration via variables d'environnement
export NEXUSDL_CONFIG=/path/to/config.yaml
export NEXUSDL_LOG_LEVEL=DEBUG
export NEXUSDL_LANGUAGE=fr
```

# 8. DÉPLOIEMENT NETLIFY

## Prérequis

- Compte Netlify (gratuit)
- CLI Netlify installé : `npm install -g netlify-cli`
- Frontend buildé

## Étape 1 : Build du Frontend

```bash
cd src/nexusdl/interfaces/web/frontend

# Installer les dépendances
pnpm install

# Build pour production
pnpm build
```

Le build sera généré dans le dossier `.next/` ou `out/` (selon la configuration).

## Étape 2 : Configuration Netlify

### Option A : Via Netlify CLI

```bash
# Se connecter à Netlify
netlify login

# Déployer
netlify deploy

# Pour déployer en production
netlify deploy --prod
```

### Option B : Via Netlify Dashboard

1. Aller sur https://app.netlify.com
2. Cliquer sur "Add new site" → "Deploy manually"
3. Glisser-déposer le dossier `out/` ou `.next/`

### Option C : Via Git (Recommandé)

1. Pousser le code sur GitHub/GitLab
2. Connecter le dépôt à Netlify
3. Configurer les paramètres de build

## Configuration netlify.toml

Créer un fichier `netlify.toml` à la racine du frontend :

```toml
[build]
  command = "pnpm build"
  publish = ".next"

[build.environment]
  NODE_VERSION = "20"
  NEXT_PUBLIC_API_URL = "https://api.nexusdl.dev/api/v1"
  NEXT_PUBLIC_WS_URL = "wss://api.nexusdl.dev/ws"

[[plugins]]
  package = "@netlify/plugin-nextjs"

[[redirects]]
  from = "/api/*"
  to = "https://api.nexusdl.dev/api/v1/:splat"
  status = 200

[[redirects]]
  from = "/ws"
  to = "wss://api.nexusdl.dev/ws"
  status = 200

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    X-XSS-Protection = "1; mode=block"
    Referrer-Policy = "strict-origin-when-cross-origin"
```

## Étape 3 : Configuration du Backend

Le backend doit être déployé séparément (VPS, Heroku, Railway, etc.).

### Variables d'Environnement Backend

```bash
# API URL publique
NEXT_PUBLIC_API_URL=https://api.nexusdl.dev/api/v1

# WebSocket URL publique
NEXT_PUBLIC_WS_URL=wss://api.nexusdl.dev/ws
```

## Étape 4 : Vérification

```bash
# Vérifier le déploiement

```

## Déploiement Continu

### GitHub Actions

Créer `.github/workflows/netlify-deploy.yml` :

```yaml
name: Deploy to Netlify

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '20'
      
      - name: Install pnpm
        uses: pnpm/action-setup@v2
        with:
          version: 8
      
      - name: Install dependencies
        run: pnpm install
        working-directory: src/nexusdl/interfaces/web/frontend
      
      - name: Build
        run: pnpm build
        working-directory: src/nexusdl/interfaces/web/frontend
      
      - name: Deploy to Netlify
        uses: nwtgck/actions-netlify@v2
        with:
          publish-dir: src/nexusdl/interfaces/web/frontend/.next
          production-branch: main
          github-token: ${{ secrets.GITHUB_TOKEN }}
          deploy-message: "Deploy from GitHub Actions"
        env:
          NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
          NETLIFY_SITE_ID: ${{ secrets.NETLIFY_SITE_ID }}
```

# 10. DÉPANNAGE
# ============================================================================

## Problèmes Courants

### Python Version Incorrecte

```bash
# Erreur : Python 3.11+ is required
# Solution : Mettre à jour Python

# Linux
sudo apt-get install python3.11

# macOS
brew install python@3.11

# Windows
# Télécharger depuis python.org
```

### Module Not Found

```bash
# Erreur : ModuleNotFoundError: No module named 'textual'
# Solution : Installer les dépendances manquantes

pip install textual
# ou
pip install -r requirements-cli.txt
```

### Display Not Available (GUI)

```bash
# Erreur : Could not connect to display
# Solution (Linux) :

# Vérifier que X11 ou Wayland est actif
echo $DISPLAY
echo $WAYLAND_DISPLAY

# Si vide, exporter la variable
export DISPLAY=:0

# Ou lancer avec xvfb (headless)
xvfb-run nexusdl --gui
```

### Port Already in Use

```bash
# Erreur : Address already in use
# Solution : Changer le port

# Backend
nexusdl --web --port 8001

# Frontend
cd src/nexusdl/interfaces/web/frontend
pnpm dev --port 3001
```

### CORS Errors (Web)

```bash
# Erreur : CORS policy blocked
# Solution : Configurer CORS dans le backend

# Éditer config.yaml
interface:
  web:
    cors_origins:
      - http://localhost:3000
      - https://nexusdl.netlify.app
```

### WebSocket Connection Failed

```bash
# Erreur : WebSocket connection failed
# Solutions :

# 1. Vérifier que le backend est lancé
curl http://localhost:8000/health

# 2. Vérifier l'URL WebSocket
echo $NEXT_PUBLIC_WS_URL

# 3. Vérifier les logs du backend
nexusdl --web --debug
```

### Build Frontend Failed

```bash
# Erreur : Build failed
# Solutions :

# 1. Nettoyer le cache
cd src/nexusdl/interfaces/web/frontend
rm -rf .next node_modules
pnpm install
pnpm build

# 2. Augmenter la mémoire Node.js
export NODE_OPTIONS="--max-old-space-size=4096"
pnpm build
```

### Netlify Deploy Failed

```bash
# Erreur : Deploy failed
# Solutions :

# 1. Vérifier les variables d'environnement
netlify env:list

# 2. Vérifier le build local
pnpm build

# 3. Vérifier les logs Netlify
netlify logs
```
