# ============================================================================
# NEXUSDL — Banque de User-Agents (user_agents.txt)
# ============================================================================
#
# Rôle :
#   Fournit une liste de User-Agents réels et à jour utilisés par
#   `core/session/user_agents.py` pour la rotation automatique lors
#   des requêtes HTTP. Cette rotation permet d'éviter le fingerprinting
#   et les blocages par les sites protégés (Cloudflare, DataDome, etc.).
#
# Format :
#   - Une ligne par User-Agent
#   - Lignes vides autorisées (ignorées)
#   - Lignes commençant par `#` = commentaires (ignorés)
#   - Sections délimitées par des commentaires de catégorie
#
# Catégories :
#   [DESKTOP_CHROME]      Chrome récent (Windows/Mac/Linux)
#   [DESKTOP_FIREFOX]     Firefox récent
#   [DESKTOP_SAFARI]      Safari macOS
#   [DESKTOP_EDGE]        Microsoft Edge
#   [DESKTOP_OPERA]       Opera / Opera GX
#   [DESKTOP_BRAVE]       Brave Browser
#   [MOBILE_ANDROID]      Chrome/Firefox/Samsung sur Android
#   [MOBILE_IOS]          Safari/Chrome sur iOS
#   [TABLET]              Tablettes Android/iPad
#   [CRAWLERS]            Crawlers légitimes (Googlebot, Bingbot)
#
# Mise à jour :
#   Ce fichier doit être mis à jour régulièrement (tous les 2-3 mois)
#   pour refléter les versions actuelles des navigateurs. Un script
#   `scripts/update_user_agents.py` peut être utilisé pour automatiser
#   la récupération depuis des sources fiables (useragentstring.com,
#   whatismybrowser.com, etc.).
#
# Utilisation :
#   >>> from nexusdl.core.session.user_agents import UserAgentsManager
#   >>> manager = UserAgentsManager()
#   >>> ua = manager.get_random(category="desktop_chrome")
#   >>> print(ua)
#   Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...
#
# ============================================================================
